# $$\boxed{\text{Examples of Languages}}$$

## $$\boxed{\text{1. Descriptive Definition}}$$

### 1. Let us consider a language L that contains strings which start with 'b' over the alphabet = {a, b, c}. Write the descriptive definition of L

$$\boxed{L = \{b, ba, bb, bc, bac, bcc,\dots \}}$$

### 2. Let us consider a language L that contains strings of even length defined over the alphabet = {a, b}

$$\boxed{L = \{\epsilon, aa, bb, ab, ba,\dots \}}$$

### 3. Let us consider a language L defined over the alphabet {a, b, c} that contains strings that end with c.

$$\boxed{L = \{c, ac, bc, cc, ccc,\dots \}}$$

### 4. Let us consider a language L defined over alphabet {a, b} that contains strings that start and end with the same letter.

$$\boxed{L = \{a,b,aa,bb,aba,bab,aaa,bbb,\dots \}}$$

### 5. Let us consider a language L defined over alphabet {a, b} that contains strings where the number of a's and b's are equal.

$$\boxed{L = \{ab,aabb,abab,bbaa,\dots \}}$$

### 6. Let L be the language defined over alphabet {a} of strings where the number of a's is a prime number.

$$
\boxed{
\begin{aligned}
\text{L} &= \{a^p \mid p \text{ is a prime number}\} \\
L &= \{a, aaa, aaaaa, aaaaaaa, \dots\} \\
L &= \{a^1, a^3, a^5, a^7, a^{11}, a^{13}, a^{17}, \dots\}
\end{aligned}
}
$$

### 7. Let us consider a language **FACTORIAL** of strings defined over $\sum = \{1,2,3,4,5,6,7,8,9\}$

$$
\boxed{
L = \{n!: n = 1,2,3,4,\dots\}
}
$$

**OR**

$$\boxed{L = \{1!, 2!, 3!, …\}}$$

### 8. Let us consider a language **PERFECT SQUARE** of strings defined over $\sum = \{a\}$

L = {c, c⁴, c⁹, c¹⁶, c²⁵, …}\\
L = {c¹, c⁴, c⁹, c¹⁶, c²⁵, c³⁶, …}$$
