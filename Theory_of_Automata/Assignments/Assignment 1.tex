\subsection*{Q4. Write the Question Here}
\textbf{Answer:}  

Example Proof:  
\begin{enumerate}
    \item Assume language $L = \{ 0^n1^n \mid n \geq 0 \}$.
    \item Show it cannot be represented by a finite automaton.
    \item Using Pumping Lemma, contradiction arises.
    \item Therefore, $L$ is \textbf{not regular}.
\end{enumerate}
